# Установка

English version: [docs/en/installation.md](../en/installation.md)

Установщики лежат на странице
[Releases](https://github.com/Quant-Ai-Assistant/Quant-Voice-Vector/releases). После установки
приложению не нужны ни учётная запись, ни интернет: модели находятся внутри установщика.

| Система | Файл |
| --- | --- |
| macOS на Apple Silicon (M1 и новее) | `..._aarch64.dmg` |
| macOS на Intel | `..._x64.dmg` |
| Windows 10 и 11, 64 бита | `..._x64-setup.exe` |
| Linux, любой дистрибутив | `.AppImage` |
| Debian и Ubuntu | `.deb` |

Приложение пока не подписано платным сертификатом разработчика, поэтому macOS и Windows
показывают предупреждение при первом запуске. Шаги ниже позволяют его пройти.

## macOS

1. Скачайте `.dmg` для своего процессора и откройте его.
2. Перетащите **Quant Voice Vector** в **Программы**.
3. Запустите приложение. macOS сообщит, что «не удалось проверить» приложение. Нажмите
   **Готово**.
4. Откройте **Системные настройки → Конфиденциальность и безопасность**, прокрутите вниз,
   нажмите **Всё равно открыть** рядом с сообщением про Quant Voice Vector и подтвердите.
5. Разрешите доступ к микрофону, когда macOS спросит.

Шаг 4 нужен один раз для каждой новой версии. То же самое из терминала:

```sh
xattr -dr com.apple.quarantine "/Applications/Quant Voice Vector.app"
```

Если вы случайно запретили доступ к микрофону, включите его в
**Системные настройки → Конфиденциальность и безопасность → Микрофон**.

## Windows

1. Скачайте `..._x64-setup.exe` и запустите.
2. SmartScreen сообщит, что приложение не распознано. Нажмите **Подробнее**, затем
   **Выполнить в любом случае**.
3. Пройдите шаги установщика.
4. Если запись не начинается, проверьте **Параметры → Конфиденциальность и защита → Микрофон**
   и разрешите классическим приложениям доступ к микрофону.

## Linux

AppImage:

```sh
chmod +x ./*.AppImage
./*.AppImage
```

Debian и Ubuntu:

```sh
sudo apt install ./*.deb
```

Микрофон используется через ALSA; PipeWire и PulseAudio работают через свой мост к ALSA.

## Где хранятся данные

Хранятся только сохранённые профили, по одному файлу `.qvoice.json` на профиль. Звук на диск
не записывается никогда.

| Система | Папка |
| --- | --- |
| macOS | `~/Library/Application Support/ai.quant.voicevector/profiles` |
| Windows | `%APPDATA%\ai.quant.voicevector\profiles` |
| Linux | `~/.local/share/ai.quant.voicevector/profiles` |

## Удаление

Удалите приложение обычным для вашей системы способом. Профили остаются в папке данных выше:
удалите и её, если хотите убрать их. Файлы, которые вы экспортировали сами, лежат там, куда вы
их сохранили.
