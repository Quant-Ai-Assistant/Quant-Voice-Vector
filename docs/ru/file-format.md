# Формат файла: `.qvoice.json`, версия 1

English version: [docs/en/file-format.md](../en/file-format.md)

Голосовой профиль — обычный файл JSON в UTF-8. Общего стандарта для голосовых профилей нет,
поэтому формат свой. Он описан в
[`schema/qvoice.v1.schema.json`](../../schema/qvoice.v1.schema.json), и Quant-Core проверяет
входящие файлы по той же схеме.

Формат — контракт между двумя проектами. Он меняется только вместе с Quant-Core, а при
несовместимом изменении растёт `version`.

## Пример

Векторы здесь обрезаны до двух чисел; в настоящем файле в каждом ровно `model.dim` чисел.

```json
{
  "format": "quant-voiceprint",
  "version": 1,
  "profile": {
    "id": "0b6f1c2e-5d0a-4a7e-9c55-3f1f6f0c2a11",
    "name": "Alexey",
    "createdAt": "2026-10-13T18:00:00Z"
  },
  "model": {
    "id": "3dspeaker_speech_campplus_sv_zh_en_16k-common_advanced",
    "sha256": "aa3cfc16963a10586a9393f5035d6d6b57e98d358b347f80c2a30bf4f00ceba2",
    "dim": 192,
    "sampleRate": 16000
  },
  "normalized": true,
  "centroid": [0.0123, -0.0456],
  "embeddings": [
    { "vector": [0.0119, -0.0461], "speechSeconds": 8.0, "source": "microphone" },
    { "vector": [0.0131, -0.0448], "speechSeconds": 8.0, "source": "file" }
  ]
}
```

## Поля

| Поле | Тип | Смысл |
| --- | --- | --- |
| `format` | строка | Всегда `quant-voiceprint` |
| `version` | целое | Версия формата, `1` |
| `profile.id` | строка | UUID профиля, создаётся при сохранении |
| `profile.name` | строка | Отображаемое имя, 1–200 символов |
| `profile.createdAt` | строка | Время создания в UTC, RFC 3339 |
| `model.id` | строка | Идентификатор модели, посчитавшей векторы |
| `model.sha256` | строка | SHA-256 файла модели ONNX, строчные шестнадцатеричные цифры |
| `model.dim` | целое | Длина каждого вектора |
| `model.sampleRate` | целое | Частота, к которой приведён звук, в герцах |
| `normalized` | логическое | Всегда `true`: векторы единичной длины (L2) |
| `centroid` | числа | Среднее векторов, нормализованное заново; для быстрого сравнения |
| `embeddings` | объекты | Векторы отдельных отрезков речи, от 5 до 20 |
| `embeddings[].vector` | числа | Вектор одного отрезка |
| `embeddings[].speechSeconds` | число | Длина чистой речи в отрезке |
| `embeddings[].source` | строка | `microphone` или `file` |

Неизвестные поля не допускаются ни на одном уровне.

## Что обязан проверить читающий

Схема покрывает типы и диапазоны. Три правила в неё не укладываются:

1. **Модель.** `model.id` и `model.sha256` совпадают с моделью читающей стороны. Файл от другой
   модели отклоняется: его векторы ни с чем нельзя сравнить.
2. **Длина.** В `centroid` и в каждом `embeddings[].vector` ровно `model.dim` чисел.
3. **Норма.** Каждый вектор единичной длины, с точностью до погрешности вычислений.

## Сравнение

Векторы нормализованы, поэтому косинусная близость — это скалярное произведение. Сравнивайте
новый вектор с `centroid` для быстрого ответа или с каждым вектором из `embeddings`, выбирая
лучший результат, если человека записывали через разные микрофоны.

## Чего в файле нет никогда

Сырого звука, текста сказанного, названия устройства, пути к исходным файлам.
